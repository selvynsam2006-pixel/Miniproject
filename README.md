The Payroll Generator is a simple Java Swing application designed to calculate monthly employee salaries based on basic pay, allowances, and deductions. It provides an easy-to-use graphical interface where users can enter salary components and instantly view the net salary calculated using the formula: Net Salary = Basic Pay + Allowances – Deductions. This project is ideal for students, beginners, and anyone learning Java Swing, offering essential features such as input validation, a clear button to reset fields, and a neatly structured layout. Built using Java and Swing, the application runs on any system with JDK installed and serves as a compact, educational payroll-calculation tool.
